1. composer require pusher/pusher-php-server
Purpose: This command installs the official Pusher PHP SDK, which allows your Laravel backend to interact with the Pusher service.
Pusher is a third-party service that provides real-time communication capabilities (e.g., broadcasting events, WebSockets) to your application.

2. composer require predis/predis
Purpose: This command installs the Predis library, a flexible and feature-complete Redis client for PHP.
Redis is an in-memory data structure store often used as a message broker for real-time applications, including Laravel’s broadcasting system.

3. npm install laravel-echo pusher-js
Purpose: This command installs Laravel Echo and Pusher JS client-side libraries via npm, 
which are used in your JavaScript frontend to listen to and handle real-time events broadcasted by Pusher.
